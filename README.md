# EEPROM Driver Development using I2C

## Overview
This project focuses on developing an EEPROM driver using I2C protocol in Embedded C.

## Features
- EEPROM Byte Write
- EEPROM Page Write
- Random Read
- Sequential Read
- Device Addressing
- ACK/NACK handling
- ACK Polling

## Tools and Hardware
- Embedded C
- I2C Protocol
- EEPROM Device
- Logic Analyzer
- Microcontroller platform

## Purpose
This project was created to understand low-level driver development, EEPROM communication, and I2C protocol handling in embedded systems.
